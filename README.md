# 🎬 MovieApp

A modern Android application for discovering and streaming movies and TV series.

MovieApp is a full-stack project built as a practical learning project, combining an Android application with a Django REST Framework backend.

## ✨ Features

* 🎬 Movies & TV Series
* 🔍 Search
* 🎛️ Movie and series filtering
* ⭐ IMDb ratings
* ⭐ User ratings
* 💬 Comments
* ❤️ Favorites
* 👤 User profile
* 🎭 Actors, directors and writers
* 🎞️ Movie and episode streaming
* 🌎 Genres, countries and languages
* 📱 Modern Android UI
* 🔐 User authentication
* 📺 Movie & series details

## 🛠️ Tech Stack

### Android

* Kotlin
* Jetpack Compose
* Material Design
* REST API

### Backend

* Python
* Django
* Django REST Framework
* PostgreSQL
* JWT Authentication

## 🎯 Project Purpose

MovieApp was created as a practical project for learning and applying backend development concepts with Django and Django REST Framework, while also gaining experience integrating a REST API with an Android application.

The project focuses on real-world concepts such as:

* REST API development
* Database relationships
* Authentication and authorization
* API filtering and searching
* User interactions
* Media and streaming data
* Android–backend communication
